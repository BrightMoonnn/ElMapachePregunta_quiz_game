# ElMapachePregunta_quiz_game
Prototipo de juego de móvil tipo Quiz

Este es el proyecto final que realicé durante mis estudios de Desarrollo de Aplicaciones Multiplataforma

Mediante la realización de este proyecto pude afianzar los conocimientos adquiridos en el ciclo y adquirir nuevos conocimientos por mi cuenta.
##  Características e Implementaciones Técnicas

El juego incluye las siguientes características:

*   **Base de datos SQLite:** En ella se encuentran las preguntas y resouestas y se guardan y actuakizan los datos de cada jugador.
*   **Sistema de recompensas por respuesta correcta:** E jugador gana monedas con cada pregunta respondida correctamente.
*   **Tienda de recompensas :** El usuario puede gastar las monedas conseguidas en esta tienda para adquirir diferentes avatares.
  

## Tecnologías Utilizadas

*   **Entorno de Desarrollo:** Android Studio
*   **Lenguaje de Programación:** Kotlin
*   **Ilustraciones:** Hechas a mano en Gimp.
